# Architektur 3D Viewer – MFH Eldagsen

Локальное веб-приложение для просмотра модели Revit `2025_0722_MFHEldagsen-LPH4-3D-Ansicht-{3D}.fbx`
(React 18 · TypeScript · Three.js r170 · React Three Fiber · Drei · Vite).

## Запуск

Требуется Node.js 18 или новее.

```bash
npm install
npm run dev        # http://localhost:5173 откроется автоматически
```

Production-сборка (например, для презентации без dev-сервера):

```bash
npm run build
npm run preview    # http://localhost:4173
```

Модель лежит в `public/models/` и загружается автоматически. Другую модель (FBX, GLB или glTF)
можно открыть кнопкой «Modell öffnen» или перетащить файл в окно. Чтобы сменить модель
по умолчанию, замените файл и путь `DEFAULT_MODEL` в `src/model/loader.ts`.

## Что извлекается из FBX (Revit 2026)

| Данные | Решение |
|---|---|
| Единицы: футы (`UnitScaleFactor 30.48`), ось Z вверх | Пересчёт в метры, ось Y вверх; геометрия не изменяется |
| Материалы в виде `ProxyObject_*` (FBXLoader их не видит) | Собственный парсер FBX: материал назначается по граням, цвет берётся из Autodesk Assets, RGB из названия, PBR-параметры по типу материала |
| Этажей нет в иерархии | Отметки определяются по верху перекрытий: EG ±0,00, OG +2,91, DG +6,04, плюс Dach и Außenanlage |
| Текстуры (bitmaps) не встроены в файл | Используются PBR-параметры без текстур; цвета можно менять в панели |

Если этажи распознаны неверно, выделите элементы, затем выберите «Geschoss zuordnen …» и нажмите
«Zuordnen». Ручное назначение сохраняется в браузере.

## Управление

| Действие | Как |
|---|---|
| Орбита / сдвиг / зум | Левая кнопка мыши / правая кнопка / колесо |
| Выделение | Клик; Shift или Ctrl + клик для нескольких; двойной клик — приблизить |
| Горячие клавиши | V — выбор, M — измерение, F — вписать, H — скрыть, I — изолировать, O — ортографическая камера, Esc — отмена |
| Этаж | Клик по кнопке — показать/скрыть; двойной клик — только этот этаж; «bis OG» — этаж и нижележащие |
| Сечения | Флажок и ползунок; кнопки EG/OG/DG — план этажа на высоте +1,20 м над чистым полом |
| Экспорт | PNG 1×–4× (до 8192 px), GLB с сохранением элементов и этажей |

## Структура

```
src/fbx/fbxMeta.ts       бинарный парсер FBX: единицы, Revit-материалы, метаданные
src/model/ModelScene.ts  загрузка, нормализация, элементы, режимы отображения, освобождение GPU-памяти
src/model/levels.ts      категории и автоматическое определение этажей
src/model/materials.ts   PBR-библиотека материалов
src/viewer/Viewer.tsx    сцена: камера, свет и HDRI, сечения (stencil caps), измерения, выбор
src/viewer/sun.ts        положение солнца (Eldagsen, 52,2° с. ш.), цветовая температура
src/ui/*                 Toolbar, Gebäudestruktur, Darstellung, нижняя панель
public/hdri/*            4 HDRI (Poly Haven, CC0), работают офлайн
```

## Ограничения

- Отрисовка: около 3 400 вызовов на кадр (1 405 мешей с подматериалами), 622 000 треугольников;
  с заливкой сечений — до 1,9 млн. На дискретной или современной встроенной видеокарте работает
  плавно; на слабых планшетах рекомендуется отключить тени.
- Заливка срезов корректна для замкнутых тел (стены, перекрытия, крыша). Незамкнутые мебельные
  поверхности могут давать мелкие артефакты.
- Освещения помещений в FBX нет, поэтому режим «Nacht» работает только за счёт HDRI и лунного света.
